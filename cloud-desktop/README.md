# Хмарний робочий стіл для студентів

Студент відкриває сайт коледжу, входить у свій акаунт і за кілька секунд отримує повноцінний
робочий стіл потрібної ОС (Ubuntu, Kali Linux, середовище для програмування, MySQL) прямо в браузері.
Нічого встановлювати не треба: уся важка робота йде на сервері коледжу.

> Автор проєкту: Олександр Мединський · листопад 2026

## Що вміє система

| Роль | Можливості |
|---|---|
| **Студент** | вхід, каталог середовищ своєї групи, запуск / пауза / зупинка / **скидання** столу, «Мої файли» (зберігаються між сесіями й видні в кожному столі), **здача роботи прямо зі столу**, оцінки й відгуки |
| **Викладач** | шаблони середовищ під предмет (образ, CPU, RAM, стартова сторінка), призначення шаблонів групам, завдання з термінами, перегляд і завантаження зданих робіт, оцінювання, **підключення до столу студента**, щоб допомогти |
| **Адміністратор** | акаунти й групи (зокрема імпорт з CSV), ліміти CPU / RAM / диска / кількості столів, автовимкнення при простої, каталог дозволених образів, навантаження сервера, примусова зупинка столів, журнал дій |

Додатково: автовимкнення неактивних столів, журнал «хто, коли і з яким середовищем працював»,
ізоляція контейнерів у мережі, метрики для Prometheus / Grafana.

## Архітектура

```
 Браузер студента
       │ HTTPS
       ▼
 ┌──────────── Nginx (80/443) ───────────────────────────────────────────┐
 │  /              → Портал (FastAPI, 127.0.0.1:8000)                    │
 │  /desktop/<id>/ → auth_request до порталу → стіл студента 127.0.0.1:N │
 └───────────────────────────────────────────────────────────────────────┘
       │                                   │
       ▼                                   ▼
 Портал ── MySQL (акаунти, групи,    Docker: один контейнер KasmVNC на студента
   │       шаблони, сесії, роботи)     (мережа cd_desktops, контейнери не бачать
   └── Docker API ──────────────────▶   один одного; ліміти CPU/RAM; без root)
                                            │
                                            ▼
                                 /srv/cloud-desktop/home/<логін>  ← «Мої_файли»,
                                 не зникає при видаленні контейнера
```

* **Портал** перевіряє вхід (JWT у HttpOnly-cookie), права й ліміти і просить Docker створити контейнер.
* **Nginx** перед кожним запитом до `/desktop/<id>/` питає портал, чи можна цьому користувачу відкрити цей стіл.
  Портал відповідає адресою контейнера й паролем KasmVNC, який Nginx підставляє сам — у браузер пароль не потрапляє.
* Порти столів відкриті лише на `127.0.0.1`, тому ззовні до контейнера можна дістатися тільки через портал.
* Файли студента лежать на диску сервера і монтуються в кожен його стіл як папка `Мої_файли`.

Детальніше про вибір технологій: [docs/analysis.md](docs/analysis.md).

## Структура

```
cloud-desktop/
├── docker-compose.yml        MySQL + портал + Nginx (+ Prometheus/Grafana у профілі monitoring)
├── .env.example              налаштування (домен, паролі, шлях до файлів)
├── portal/                   портал: FastAPI + SQLAlchemy + Docker SDK
│   ├── app/
│   │   ├── main.py           запуск, фонове автовимкнення, /metrics
│   │   ├── models.py         таблиці: users, groups, templates, desktop_sessions, assignments, submissions, audit_log
│   │   ├── sessions_service.py  запуск/пауза/зупинка/скидання столів, ліміти, простій
│   │   ├── drivers/          docker_driver.py (KasmVNC-контейнери), fake_driver.py (без Docker)
│   │   ├── routers/          API: auth, templates, sessions (+ /api/proxy/auth), files, assignments, teacher, admin
│   │   └── static/           інтерфейс (HTML/CSS/JS без фреймворків)
│   └── tests/                автотести (pytest)
├── nginx/templates/          конфіг Nginx (HTTPS, проксі столів, WebSocket)
├── images/                   власні образи: dev-desktop (VS Code + мови), mysql-desktop (MySQL + DBeaver)
├── scripts/                  встановлення сервера, брандмауер, сертифікати, бекапи, тест навантаження
├── monitoring/               Prometheus і Grafana
└── docs/                     аналіз, інструкції для студента, викладача й адміністратора, план робіт
```

## Швидкий старт без Docker (розробка інтерфейсу)

Портал можна запустити на будь-якому ПК з Python 3.11+. Робочі столи при цьому імітуються (`CD_DRIVER=fake`).

```bash
cd cloud-desktop/portal
pip install -r requirements-dev.txt
CD_DEMO_SEED=1 CD_ADMIN_PASSWORD=Admin12345 uvicorn app.main:app --reload
# відкрийте http://127.0.0.1:8000
```

Демо-акаунти: `admin / Admin12345`, `teacher / Teacher123`, `student1`…`student3 / Student123`.

Тести: `cd portal && python -m pytest -q`.

## Розгортання на сервері коледжу

Потрібен Ubuntu Server 22.04 або 24.04 (для початку підійде старий ПК чи віртуальна машина).

```bash
sudo git clone <репозиторій> /opt/cloud-desktop-src && sudo cp -r /opt/cloud-desktop-src/cloud-desktop /opt/cloud-desktop
cd /opt/cloud-desktop
sudo bash scripts/install-server.sh       # Docker, брандмауер, папки, .env з випадковими паролями
sudo nano .env                            # CD_DOMAIN, CD_ADMIN_PASSWORD
sudo bash scripts/build-images.sh         # образи столів (10–30 хв)
sudo bash scripts/selfsigned-cert.sh      # тимчасовий сертифікат
sudo docker compose up -d --build
sudo bash scripts/letsencrypt.sh admin@college.edu.ua   # справжній сертифікат (потрібен публічний домен)
```

Далі: увійдіть як адміністратор, створіть групи й акаунти (або імпортуйте CSV), призначте викладачам групи.
Повна інструкція: [docs/admin-guide.md](docs/admin-guide.md).

### Перевірка першого столу вручну (тиждень 1)

```bash
docker run -d --name desk-test --shm-size=512m --memory=2g --cpus=1 \
  -p 6901:6901 -e VNC_PW=changeme -v /srv/students/test:/home/kasm-user \
  kasmweb/ubuntu-jammy-desktop:1.17.0
# https://адреса-сервера:6901  (логін kasm_user, пароль changeme)
```
