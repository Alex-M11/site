## Висновок і вибір

* Guacamole добре показує екран, але не вміє створювати й видаляти середовища — довелося б писати те саме керування окремо.
* Kasm Workspaces найближчий за ідеєю, але він універсальний і бізнесовий: немає завдань, здачі робіт, ролі викладача.
  Розширювати його складно, а безкоштовна версія обмежена.
* Azure Virtual Desktop платний, дані йдуть у хмару, а налаштування складне для коледжу.

**Обрано:** готові **образи робочих столів Kasm** (`kasmweb/*`) як основу, бо в них уже є KasmVNC (робочий стіл у браузері
через HTTPS/WebSocket), а **портал свій**: Python + FastAPI + MySQL + Docker SDK. Так ми використовуємо найкращу частину Kasm
(легкі контейнерні столи) і робимо все, що потрібно саме для навчання.

## Чому саме такий стек

| Частина | Вибір | Альтернатива і чому ні |
|---|---|---|
| Ізоляція | Docker | LXD — менше готових образів робочих столів; ВМ на кожного — у 3–5 разів більше RAM |
| Стіл у браузері | KasmVNC (вбудований в образи) | noVNC + окремий VNC-сервер — гірша якість і більше налаштувань; Guacamole — ще один сервіс |
| Бекенд | FastAPI (Python) | Node.js теж підходить; Python простіший для студентів і має офіційний Docker SDK |
| БД | MySQL 8 | PostgreSQL рівноцінний; MySQL вивчають на парах |
| Інтерфейс | HTML + CSS + JS без фреймворку | React — потребує збірки; тут достатньо кількох екранів |
| Проксі | Nginx з `auth_request` | Traefik — складніша динамічна маршрутизація; `auth_request` дає перевірку доступу до кожного столу одним рядком |
| Windows | KVM / Proxmox (наступний етап) | Windows у Docker не працює як робочий стіл; потрібна ВМ і ліцензія |

## Windows-середовища

Портал побудований через «драйвер» (`portal/app/drivers/base.py`). Зараз є Docker-драйвер.
Для Windows план такий: ВМ на KVM/Proxmox із шаблону (linked clone), доступ через RDP,
а в браузер його передає Apache Guacamole (guacd) або KasmVNC-шлюз. Новий драйвер реалізує ті самі методи
`create / start / stop / pause / remove / endpoint`, і решта порталу не змінюється.
Ліцензування: перевірити програму Microsoft для навчальних закладів (Azure Dev Tools for Teaching / освітні ліцензії)
до початку пілоту з Windows.
