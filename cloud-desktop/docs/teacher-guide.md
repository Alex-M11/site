# Інструкція для викладача

Ваш акаунт створює адміністратор і призначає вам групи. Після входу в меню з'явиться розділ **Викладач**.

## 1. Шаблон середовища під предмет

**Шаблони → + Новий шаблон**

* **Назва і предмет** — так студенти побачать його в каталозі (картки групуються за предметом).
* **Опис** — що встановлено і що робити; можна вказати логіни до БД тощо.
* **Базовий образ** — Ubuntu, Kali Linux, VS Code, програмування, MySQL. Список дозволених образів задає адміністратор.
* **CPU і пам'ять** — для більшості лабораторних достатньо 1 CPU і 2048 МБ; Kali з Wireshark/Burp — 2 CPU і 3072 МБ.
  Що більше ресурсів, то менше студентів одночасно вмістить сервер.
* **Стартова сторінка браузера** — наприклад, сторінка з умовою лабораторної.
* **Групи** — кому показувати шаблон. Можна вимкнути шаблон (не видаляючи), щоб сховати його від студентів.

Змінювати й видаляти можна лише власні шаблони. Видалити шаблон, у якого є столи студентів, не можна — вимкніть його.

## 2. Завдання

**Завдання й роботи → + Нове завдання**: назва, умова, група, середовище, термін здачі.
Студенти побачать завдання в розділі **Завдання** і кнопку **Здати роботу** над робочим столом.

### Автоперевірка (необов'язково)

У формі завдання розгорніть **🤖 Автоперевірка** і напишіть скрипт bash. Після кожної здачі він виконується
в окремому контейнері: здані файли лежать у поточній папці (лише для читання), мережі немає, є ліміт часу.
Код завершення 0 — «пройдено», інший — «не пройдено»; усе, що скрипт виведе, ви побачите біля роботи
(і студент, якщо дозволите). Приклад для Python:

```bash
set -e
test -f lab1.py || { echo "Немає файлу lab1.py"; exit 1; }
echo "3 4" | python3 lab1.py > /tmp/out.txt
grep -qx "7" /tmp/out.txt && echo "Тест 1: OK"
```

Образ для перевірки (python, gcc, node) обирається зі списку, який задає адміністратор. Змінили скрипт —
натисніть **🤖 Перевірити всіх заново** у списку робіт. Автоперевірка не замінює оцінку: оцінку ставите ви.

## 3. Перевірка робіт

**Завдання й роботи → Роботи** — список усієї групи:

* хто здав (і чи вчасно), а хто ні;
* файли можна завантажити одним кліком;
* **Оцінити** — оцінка у довільному форматі (`10/12`, `зараховано`) і відгук; студент побачить їх одразу;
* якщо студент здасть роботу повторно, оцінка скидається і роботу треба перевірити знову.

## 4. Допомога студенту на парі

**Столи студентів** — усі столи ваших груп і їхній стан.

* **🛟 Підключитися** відкриває стіл студента в режимі **лише перегляду**: ви бачите екран, але не можете нічого змінити.
  Щоб показати, що виправити, натисніть **🖱 Взяти керування**; повернутися — **👁 Лише перегляд**.
  Студент бачить, що ви підключені (і в якому режимі), а кожне підключення записується в журнал.
  Роздільна здатність екрана студента при цьому не змінюється — картинка масштабується у вашому вікні.
* **Скинути** допоможе, якщо студент зламав середовище: стіл створюється заново, `Мої_файли` залишаються.
* **Зупинити** звільнить пам'ять сервера після пари.

## 5. Студент забув пароль

**Мої групи → 🔑 Скинути пароль** біля студента. Портал покаже тимчасовий пароль (лише один раз) — продиктуйте його.
Старі входи студента завершуються, а після входу з тимчасовим паролем він одразу придумає власний.

## Поради для пари

* Попросіть студентів запустити стіл на початку пари — перший запуск займає до хвилини.
* Нагадайте: зберігати роботу тільки в `Мої_файли`.
* Орієнтир: одна група (15–20 столів) — сервер із 32 ГБ RAM. Ліміт пам'яті шаблону — це стеля, реально стіл займає 1–2 ГБ. Точні числа дає тест навантаження.
